# Clicker Forge

A polished, beginner-friendly incremental clicker game built entirely with Python's `turtle` module.

## Features

- Animated click target and particle effects
- Click-power, auto-production, and multiplier upgrades
- Three visual themes
- Fortune wheel with bonuses and risks
- Rebirth system for permanent bonuses
- Automatic local save progress
- Responsive 960×600 game window

## Run

```bash
python "clicker game.py"
```

Progress is saved automatically to `clicker_save.json` next to the game file.
